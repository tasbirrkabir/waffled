# Waffled Sreemangal — Website Build Kit

A developer-ready Markdown specification pack for designing and building a polished website for **Waffled Sreemangal**, a waffle/dessert spot in Sreemangal, Bangladesh.

## Files in this pack

1. `01-research-and-facts.md` — research summary, sources, confidence levels, and facts to verify.
2. `02-product-requirements.md` — goals, scope, requirements, and success criteria.
3. `03-sitemap-and-user-flows.md` — information architecture, page sections, and conversion journeys.
4. `04-visual-direction-and-design-system.md` — visual concept, colors, typography, components, and responsive behavior.
5. `05-page-copy-en.md` — suggested English website copy, with editable/conditional content clearly marked.
6. `06-menu-content-template.md` — content model and owner-verification template for items and prices.
7. `07-seo-and-local-discovery.md` — local SEO, metadata, structured data, and search visibility checklist.
8. `08-technical-implementation.md` — recommended stack, component architecture, accessibility, performance, and integrations.
9. `09-assets-and-content-checklist.md` — photography, brand files, content, and permissions checklist.
10. `10-agent-build-prompt.md` — copy/paste prompt for an AI coding agent.
11. `11-launch-and-qa-checklist.md` — pre-launch verification and QA.

## Recommended website concept

Build a **mobile-first, high-energy, photo-led website** with a distinctive visual identity: bold color, warm food photography, expressive but clean typography, and a clear menu/location path. Use the shop's own vivid interior and brand personality as a starting point; do not copy another waffle brand's logo, layout, copy, or visual identity.

The most valuable first release is a fast, polished website with a menu, real location/directions, click-to-call, opening hours, gallery, reviews/social proof, and clear contact actions. Online checkout, delivery integrations, loyalty accounts, and table booking are not assumed requirements.

## Important implementation rule

Research is not a substitute for owner approval. Treat phone, hours, exact address, menu items, prices, delivery availability, and social links as **provisional until Waffled confirms them**. Do not publish guessed information or fake reviews, ratings, discounts, or claims.

## Suggested build order

1. Get owner confirmation using `01-research-and-facts.md` and `06-menu-content-template.md`.
2. Collect logo, menu, authentic food photos, interior photos, and social links from the owner.
3. Build the responsive menu/location-first website from `02`–`04` and `08`.
4. Replace all placeholders using `05` and `06`.
5. Complete SEO, accessibility, and QA from `07` and `11`.

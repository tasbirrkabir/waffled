# 11 — Launch & QA Checklist

## A. Owner sign-off

- [ ] Official name/wordmark spelling approved.
- [ ] All pages and final copy approved.
- [ ] All menu item names/descriptions/prices confirmed.
- [ ] Phone number confirmed; call function tested.
- [ ] Exact address and Google Maps pin confirmed by a person who knows the location.
- [ ] Opening hours and exceptions confirmed.
- [ ] Dine-in/takeaway/delivery/ordering statements approved.
- [ ] Social links confirmed as official.
- [ ] All images have reuse permission and represent actual products/store.
- [ ] Review link and any visible rating/quotes checked for accuracy.
- [ ] Domain ownership and hosting access agreed.

## B. Functional checks

- [ ] Every header link goes to the right location/route.
- [ ] View Menu scrolls/navigates correctly.
- [ ] Every item price is readable and correct.
- [ ] Category filters work on touch and keyboard.
- [ ] Directions opens the exact approved pin.
- [ ] Phone CTA opens the dialer with the correct number.
- [ ] WhatsApp CTA is absent unless confirmed and tested.
- [ ] Social icons link to official profiles, not placeholders.
- [ ] FAQ controls work with keyboard and screen readers.
- [ ] Mobile sticky action bar does not cover content or the browser's bottom UI.
- [ ] Page still works if a map/review embed fails or is blocked.

## C. Visual and responsive checks

- [ ] Test at 360px, 390px, 768px, 1024px, 1440px, and a wide desktop viewport.
- [ ] No horizontal overflow.
- [ ] Hero image crop is appropriate at each breakpoint.
- [ ] Prices and menu labels wrap cleanly.
- [ ] Buttons have clear hover, pressed, disabled, and focus states where applicable.
- [ ] Contrast passes for text and buttons.
- [ ] Reduced-motion preference is respected.
- [ ] Images do not shift layout after loading.

## D. Content accuracy

- [ ] Search for `TODO`, `PLACEHOLDER`, `[confirmed`, `OWNER-APPROVED`, `Lorem`, and sample prices.
- [ ] No example JSON values are visible to customers.
- [ ] No unsupported health, ingredient, freshness, quality, or “best” claim.
- [ ] No invented testimonials, reviews, awards, or live ratings.
- [ ] Opening hours do not contradict the Google Business Profile.
- [ ] Menu data matches the latest owner-approved menu.
- [ ] English/Bangla translations have been proofread if both are present.

## E. SEO and sharing

- [ ] Unique page title and meta description.
- [ ] Canonical URL matches the final domain.
- [ ] HTTPS works; HTTP redirects to HTTPS.
- [ ] `robots.txt` does not block production accidentally.
- [ ] `sitemap.xml` is reachable and accurate.
- [ ] Local business structured data contains only verified values.
- [ ] Rich Results/schema validation completed.
- [ ] Open Graph image/title/description tested in a social preview checker.
- [ ] Search Console verified and sitemap submitted, if owner grants access.
- [ ] Google Business Profile website link updated after launch.

## F. Performance and accessibility

- [ ] Images compressed and responsive.
- [ ] Hero/LCP image prioritized; below-the-fold images lazy-loaded.
- [ ] No unnecessary third-party scripts or autoplay media.
- [ ] Keyboard-only navigation is possible.
- [ ] Skip link and visible focus states work.
- [ ] Headings, landmarks, image alt text, and labels checked.
- [ ] Page tested on a real Android phone and a slower connection.
- [ ] Lighthouse/Core Web Vitals reviewed; issues triaged rather than blindly chasing scores.

## G. Launch / operations

- [ ] Preview URL shared with the owner and approval recorded.
- [ ] Production domain and deployment owner documented.
- [ ] Analytics/privacy decisions documented.
- [ ] Menu update process explained to the owner.
- [ ] Domain renewal and hosting billing owner established.
- [ ] Backups/version control enabled where applicable.
- [ ] Post-launch links tested again from social media/mobile.
- [ ] One-week follow-up to collect corrections and check menu accuracy.
